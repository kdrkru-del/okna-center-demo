# «ОКНА-ЦЕНТР» | Лаборатория ремонта (Владивосток)
## Современный промышленный веб-сайт по утеплению фасадного алюминиевого остекления термокоробами

* **Работающий сайт (GitHub Pages):** [https://kdrkru-del.github.io/okna-center-demo/](https://kdrkru-del.github.io/okna-center-demo/)

## 2. Технологический стек

* **Фреймворк:** React 19
* **Язык:** TypeScript 5.7+ (строгая проверка типов, `verbatimModuleSyntax`)
* **Сборщик:** Vite 8 (`base: '/okna-center-demo/'`)
* **Стилизация:** Tailwind CSS v4 (@tailwindcss/vite)
* **Иконки:** Lucide React
* **Оптимизация графики:** Progressive JPEG/PNG, сжатие с сохранением резкости до 1600px.

## 5. Редактирование контента и изображений

1. **Тексты, контакты и услуги:**
   Все тексты, телефоны, адреса и описания услуг собраны в одном файле:
   `src/data/content.ts`. Для изменения достаточно отредактировать этот файл.

2. **Добавление фотографий объектов:**
   * Поместите новые фотографии в папку `public/images/projects/`.
   * Добавьте объект в массив `PROJECTS` в файле `src/data/content.ts`.

3. **Цвета и стили:**
   Стили и темы настраиваются через классы Tailwind CSS в компонентах и базовые директивы в `src/index.css`.

## 6. Резервный сценарий и подключение отправки заявок

В текущей статической версии сайта на GitHub Pages реализован **честный и прозрачный сценарий**:
* Пользователю **не выводится обманчивое сообщение** «Заявка отправлена», если серверный бэкенд не подключен.
* При заполнении формы проводится клиентская валидация (имя, маска телефона `+7 (XXX) XXX-XX-XX`, тип объекта, комментарий).
* После заполнения посетителю моментально предлагаются **реальные каналы связи**:
  * **Прямой переход в WhatsApp** (+7 914 072-22-22) с автоматически сформированным текстом спецификации.
  * **Отправка официального письма на Email** (`teplo_al@mail.ru`).
  * **Копирование готового текста заявки** в буфер обмена в один клик.

### Подключение автоматической отправки на бэкенд:

#### Вариант 1: Telegram-бот через Serverless Function
Если сайт размещается на платформе с поддержкой API-эндпоинтов (Vercel, Netlify, Cloudflare Workers):
```ts
// api/send-lead.ts
export async function POST(request: Request) {
  const data = await request.json();
  const token = process.env.TELEGRAM_BOT_TOKEN;
  const chatId = process.env.TELEGRAM_CHAT_ID;
  
  const text = `🔥 Новая заявка на термокороба (Окна-Центр):\nИмя: ${data.name}\nТел: ${data.phone}\nОбъект: ${data.structureType}\nПараметры: ${data.footage}`;
  
  await fetch(`https://api.telegram.org/bot${token}/sendMessage`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ chat_id: chatId, text })
  });
  
  return Response.json({ success: true });
}
```

#### Вариант 2: Email через Resend или SMTP
```ts
import { Resend } from 'resend';
const resend = new Resend(process.env.RESEND_API_KEY);

await resend.emails.send({
  from: 'leads@okna-center.pro',
  to: 'teplo_al@mail.ru',
  subject: 'Заявка на расчет остекления',
  text: `Имя: ${data.name}, Телефон: ${data.phone}, Объект: ${data.structureType}`
});
```

## 7. Публикация на GitHub Pages

Публикация автоматизирована через **GitHub Actions**:
1. При любом push в ветку `main` срабатывает workflow `.github/workflows/deploy.yml`.
2. Проект собирается на виртуальной машине Ubuntu с помощью `npm ci && npm run build`.
3. Скомпилированная директория `dist` публикуется в ветку `gh-pages`.
4. GitHub Pages моментально обновляет сайт по адресу:
   **https://kdrkru-del.github.io/okna-center-demo/**
