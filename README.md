# «ОКНА-ЦЕНТР» | Лаборатория ремонта (Владивосток)
## Современный промышленный веб-сервис по утеплению фасадного алюминиевого остекления термокоробами

Готовый, полностью рабочий проект веб-сервиса компании **«ОКНА-ЦЕНТР» (Лаборатория ремонта)**, разработанный взамен устаревшего шаблонного сайта uKit (`https://hotaluminum.ukit.me/`).

## 3. Технологический стек

* **Фреймворк**: React 19 (Strict Mode, Hooks, Memo)
* **Язык**: TypeScript 5.7+ (строгая типизация)
* **Сборщик**: Vite 8 (Hot Module Replacement, оптимизированный production-бандл)
* **Стилизация**: Tailwind CSS v4 (@tailwindcss/vite)
* **Иконки**: Lucide React
* **Доступность и UX**: Семантическая разметка (WAI-ARIA), фокус с клавиатуры, поддержка `prefers-reduced-motion`, мобильная адаптивность 360–1440+ px.

## 5. Инструкция по запуску и сборке

### Требования
* Node.js версии **18.0.0** или новее (проверено на Node.js v24.15.0)
* Менеджер пакетов `npm` или `pnpm` / `yarn`

### 1. Установка зависимостей
```bash
cd okna-center-pro
npm install
```

### 2. Запуск в режиме разработки (с горячей перезагрузкой)
```bash
npm run dev
```
Сервер запустится по адресу: `http://localhost:5173` (или свободном порту).

### 3. Production-сборка
```bash
npm run build
```
Скомпилированные статические файлы будут сохранены в директорию `dist/`.

### 4. Предварительный просмотр сборки
```bash
npm run preview -- --port 4173
```
Открыть в браузере: `http://localhost:4173`.

## 6. Честный сценарий и подключение бэкенда для заявок

В текущей версии реализован **прозрачный резервный сценарий**: при отправке формы пользователю не выводится обманчивое сообщение «Заявка сохранена в базе», если бэкенд не настроен. Вместо этого:
1. Данные проверяются и форматируются в структурированный текст заявки.
2. Пользователь может в один клик отправить заявку напрямую в **WhatsApp инженеру** (`+7 914 072-22-22`), на **Email компании** (`teplo_al@mail.ru`) или скопировать готовый текст.

### Как подключить автоматическую отправку (бэкенд):

#### Вариант А: Telegram-бот (самый быстрый для оконных компаний)
Создайте серверную функцию (например, в Vercel Serverless, Cloudflare Workers или Express) и добавьте запрос к Telegram Bot API:
```ts
// api/send-lead.ts
export async function sendToTelegram(formData: LeadFormData) {
  const token = process.env.TELEGRAM_BOT_TOKEN;
  const chatId = process.env.TELEGRAM_CHAT_ID;
  const text = `🔥 Новая заявка с сайта:\nИмя: ${formData.name}\nТел: ${formData.phone}\nОбъект: ${formData.structureType}\nСмета: ${formData.footage}`;

  await fetch(`https://api.telegram.org/bot${token}/sendMessage`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ chat_id: chatId, text, parse_mode: 'HTML' })
  });
}
```

#### Вариант Б: Email через Resend / SMTP
Используйте сервис [Resend](https://resend.com) или SMTP-транспорт:
```ts
import { Resend } from 'resend';
const resend = new Resend(process.env.RESEND_API_KEY);

await resend.emails.send({
  from: 'leads@okna-center.pro',
  to: 'teplo_al@mail.ru',
  subject: 'Новая заявка на термокороба',
  text: `Заявка от ${formData.name}, телефон ${formData.phone}`
});
```

#### Вариант В: CRM (AmoCRM / Битрикс24)
Отправляйте входящий лид через официальный Webhook в AmoCRM:
```bash
POST https://ваш-домен.amocrm.ru/api/v4/leads/complex
```
